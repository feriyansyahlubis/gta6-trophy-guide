    The road to the platinum, in the order to play it. Each stage lists the trophies it earns, built from the official descriptions — which story chapters and missions, which collectibles and counts. Tick trophies off in the Tracker as you go; this page counts your progress per stage.

      Read this before you play. These trophies are flagged missable because the official description ties them to one specific moment, set-up or second attempt — a named rival, an undetected robbery, a single Combat Focus, a choice when it is offered. The rest of the list is replayable or grindable, so it can wait. Where the description does not pin down a place or a step, the guide says so instead of inventing one.

        Sources & method

        Every trophy's name, description and grade is shown exactly as PlayStation publishes it, taken from the official list as carried by Exophase and PSNProfiles — the two agreed on every name, description and grade. Every guide is written in our own words for this guide; it may draw on other guides and wikis, but it never copies their text. Each trophy's guide names its sources beside it.

          How the roadmap and missable flags were built

          Both are built from the official descriptions alone: which story chapters and missions (Chapter 1–4, the named missions, the final mission), which collectibles and counts (42 Shooting Range challenges, 14 drone-race locations, 100 vehicles, 100 WAiNK It locations, 52 areas, 18 meditation spots, 8 garage properties, 3 card sets, 9 gangs), and which trophies need one specific moment. A specific location or step with no source gets no credit in this guide — where a fact is not pinned down by a source, the guide says so.

          Your progress stays yours

          This app is static files and works with the network off. Your checklist, notes and settings are saved only in this browser (localStorage) and never leave it, except in the export file you choose to download. Import reads only the file you pick. No Rockstar logo, official artwork or game screenshot is used anywhere: the look is our own.
